# Instagram Profile Checklist

Use this once the client has manually created the Instagram account and converted it to **Business** (see `meta-business-setup-sop.md` Phase 2).

All work below is done by a human inside the Instagram app or instagram.com with the client's authorization. Nothing here is automated.

---

## Handle

- [ ] Handle chosen from the intake's approved handle list.
- [ ] Handle is consistent with the Facebook Page username where possible.
- [ ] Avoid extra numbers, underscores, or filler — keep it short and brand-aligned.

## Account type

- [ ] Account is set to **Professional → Business**.
- [ ] Business category matches the Facebook Page primary category.

## Profile basics

- [ ] Profile photo: same square logo used on Facebook.
- [ ] Name field (the bold display name): use the brand name plus a service keyword if there's room (e.g., "A-1 Sealcoating | NJ Driveways").
- [ ] Bio: 3 short lines covering what they do, service area, and a call to action.
- [ ] Link: the canonical website URL. If using a link-in-bio tool, set it up only after the homepage exists.

## Contact options

- [ ] Phone number set and visible as a contact button.
- [ ] Email set and visible as a contact button.
- [ ] Address set with directions button **only if** the client has a real visitable storefront. Service-area businesses should leave this off.

## Connected accounts

- [ ] Instagram is linked to the Facebook Page via the Page's Linked accounts setting.
- [ ] Both assets appear inside the Meta Business Portfolio.

## Highlights

- [ ] At least one Highlight cover designed (placeholder is fine on day one), e.g. "Driveways", "Sealcoating", "Reviews".
- [ ] No more than five Highlights to start. Quality over quantity.

## Content (before any ad runs)

- [ ] First three feed posts published (see `organic-post-template.md`).
- [ ] First post has the strongest hero photo.
- [ ] Captions use the standard CTA pattern from the launch plan.
- [ ] At least one Story published so the profile ring is active.

## Access and roles

- [ ] Client owns the Instagram login.
- [ ] Instagram is added as a business asset inside the Meta Business Portfolio.
- [ ] Agency manages via partner access on the portfolio. No password sharing.

## Compliance

- [ ] Bio claims match what's on the website and the Page.
- [ ] No promises the business can't keep.
- [ ] No restricted content unless explicitly cleared.

## Sign-off

- [ ] Client has reviewed the profile on a phone.
- [ ] Client has approved in writing.
