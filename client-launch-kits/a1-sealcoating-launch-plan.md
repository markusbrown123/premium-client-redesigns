## Handle options for Instagram

Pick one with the client, then secure it. Listed in order of preference for a sealcoating business serving NJ:

1. `@a1sealcoatingllc` — matches the legal name, easy to verify, future-proof.
2. `@a1sealcoatingnj` — strongest local signal; best if NJ stays the only market.
3. `@a1asphaltservices` — broader if the business expands beyond sealcoating into paving/asphalt repair.

The Facebook Page username should match whichever IG handle is chosen, where available.

---

## What must be done manually in Meta

These steps require the client to be present and driving the keyboard. The agency guides on a screen share. No credentials, 2FA codes, or payment details ever pass through the agency.

1. Create or log into the owner's personal Facebook account.
2. Create the Facebook Page for A-1 Sealcoating LLC.
3. Create the Instagram account (suggested handle from the list above).
4. Convert Instagram to a Business account.
5. Connect the Page and Instagram via Page settings → Linked accounts.
6. Create a Meta Business Portfolio at business.facebook.com.
7. Create the ad account inside the portfolio (currency USD, time zone America/New_York, country US).
8. Add a payment method (client enters card).
9. Verify the domain `a1sealcoating.llc` via DNS TXT record at the registrar.
10. Add the Meta Pixel later — only once the website has a working quote form or call-tracking event worth firing on.
11. Grant the agency partner access through Business Manager → Partners. Never share passwords.

---

## What can be automated later with official APIs

After partner access is in place and the client signs off on scope:

- **Campaign drafts** — generate the next month's campaign structure as a draft for human review.
- **Creative naming** — auto-apply `naming-conventions.md` to creatives uploaded to the shared drive.
- **UTM generation** — build the standard UTM string for any new destination URL.
- **Reporting exports** — pull Ads Insights into a weekly sheet.
- **Ad performance summaries** — turn weekly exports into a one-page client summary.
- **Campaign creation** — only once the agency holds approved Meta Marketing API access and A-1 has authorized it in writing.

No automation will log in as A-1, sign up accounts, handle 2FA, or scrape Meta surfaces.

## First paid campaign

Apply `ad-campaign-template.md` and `naming-conventions.md`.

### Objective recommendations

In order of preference for A-1 Sealcoating:

1. **Calls** — homeowners typically call for a sealcoating quote. The phone is the fastest path to a job.
2. **Leads** — a Meta instant form is a strong backup. Use if the client is fast at calling leads back (target: within 5 minutes).
3. **Traffic** — only after we confirm https://a1sealcoating.llc has a clean quote form and the Pixel is firing. Otherwise we are paying for clicks that go nowhere.

Default for launch: **Calls**.

### Campaign

- **Name:** `A-1 Sealcoating — Local Driveway Leads`
- **Internal name (per `naming-conventions.md`):** `a1seal_calls_nj_driveways_2026-05`
- **Objective:** Calls
- **Special ad category:** none
- **Budget optimization:** off (budget at ad set level for first launch)

### Ad set

- **Display name:** `Residential Driveways — Local Radius`
- **Internal name:** `res-homeowners_monmouth-nj_auto_2026-05`
- **Conversion location:** Phone call
- **Performance goal:** Maximize calls
- **Location:** radius around A-1's base in NJ — confirm exact zips with Steve. Default starting radius 20 miles.
- **Age:** 28–65
- **Gender:** All
- **Detailed targeting:** broad. Layer in `Homeownership: Homeowners` only if Meta still surfaces that demographic at launch time.
- **Placements:** Advantage+ placements.
- **Schedule:** start tomorrow, no end date.
- **Daily budget:** conservative starter — confirm with client; suggested floor for meaningful learning is in the $20–$40/day range for the first 7 days.
