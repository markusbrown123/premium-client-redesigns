# Facebook Page Checklist

Use this once the client has manually created the Page (see `meta-business-setup-sop.md` Phase 2).

All work below is done by a human inside Facebook's Page editor with the client's authorization. Nothing here is automated.

---

## Identity

- [ ] Page name matches the legal/DBA name on the intake.
- [ ] Username (`facebook.com/yourbusiness`) is set, short, and matches Instagram handle where possible.
- [ ] Profile photo: square, centered, recognizable at small sizes (usually the logo).
- [ ] Cover photo: high-resolution, on-brand, shows the work or the truck/equipment, not a stock image.

## Categories

- [ ] Up to three categories chosen from the intake.
- [ ] Primary category is the most specific and accurate one (e.g., "Paving & Asphalt Service", not just "Contractor").

## About / contact

- [ ] Short description (one sentence, what the business does + service area).
- [ ] Long description (3–5 sentences, more detail, license/insurance if applicable).
- [ ] Phone number — the same number listed on the intake and on the website.
- [ ] Website — full URL with `https://`.
- [ ] Email — public, monitored.
- [ ] Address or service area set appropriately. If service-area only, hide the street address.
- [ ] Hours match the intake.

## Action button

- [ ] Action button set. For local service clients, default to **Call Now**. If lead form is the primary conversion, set **Sign Up** or **Send Message** instead.
- [ ] Tested: clicking the action button on a phone actually triggers the intended action.

## Services

- [ ] Each primary and secondary service from the intake added under the Services section.
- [ ] Each service has a short description and (where allowed) a price range.

## Tabs / layout

- [ ] Reviews tab enabled (unless client explicitly opts out).
- [ ] Photos tab populated (see Content below).
- [ ] Posts tab visible by default.

## Content (before any ad runs)

- [ ] Profile + cover photos uploaded.
- [ ] At least three organic posts published (see `organic-post-template.md`).
- [ ] At least six work photos uploaded to the Photos tab.

## Access and roles

- [ ] Client is the Page admin/owner.
- [ ] Agency has partner access via Meta Business Portfolio. No password sharing.
- [ ] Any prior third-party admins audited and removed if no longer authorized.

## Compliance

- [ ] No claims in the description, services, or pinned post that exceed what the business can deliver.
- [ ] License/insurance language matches the intake.
- [ ] No restricted content (e.g., regulated industries, specific health claims) unless cleared.

## Sign-off

- [ ] Client has reviewed the live Page on desktop and mobile.
- [ ] Client has approved in writing (email or signed sheet).
